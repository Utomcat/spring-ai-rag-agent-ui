# 功能特性详细说明

## 👥 双角色体系

### 管理员（ADMIN）

侧边栏菜单按功能分为 6 个组：

- **📊 数据概览**（独立菜单项）

- **📁 知识管理**
    - 知识分类、文档管理、文档标签、入库任务

- **🔐 安全与权限**
    - 用户管理、租户管理、知识库权限

- **⚙️ 系统运维**
    - 模型配置、系统配置、数据保留

- **🤖 智能运维**
    - 问答测试、评估体系、Agent 管理、消息反馈

- **🔗 开放平台**
    - API 密钥、Webhook、插件管理

- **👤 个人中心**（独立菜单项）

以下为各模块详细说明：

- **📊 数据概览仪表盘**
    - 核心指标卡片（用户总数、知识文档、向量片段、今日问答）
    - 近 7 日助手回答次数趋势折线图
    - 近 7 日新注册用户柱状图
    - 分类文档数量占比饼图
    - 分类文档数量条形图

- **👤 用户管理**
    - 用户列表查询与分页
    - 新增/编辑/删除用户
    - 启用/禁用用户账号
    - 用户角色分配

- **📁 知识分类管理**
    - 分类增删改查
    - 分类层级展示

- **📄 文档管理**
    - 多格式文档上传（txt / pdf / doc / docx / md）
    - 文档自动解析与向量化
    - 按分类筛选文档
    - 删除文档（同步清除向量数据）

- **🏷️ 文档标签管理**
    - 标签增删改查
    - 文档多标签绑定与分类筛选

- **📥 入库任务管理**
    - 入库任务列表与状态跟踪
    - 任务重试与失败处理

- **🏢 租户管理**
    - 租户增删改查
    - 租户配额管控

- **🔐 知识库权限管理**
    - 知识库权限分配与查询
    - 按租户/用户/分类粒度管控

- **🤖 AI 模型配置**
    - 模型配置增删改查
    - 模型启用/禁用管理

- **📊 评估体系**
    - 评估数据集管理（多 tab 页）
    - 评估任务管理（多 tab 页）

- **🧠 Agent 管理**
    - 执行链路查看（多 tab 页）
    - 长期记忆管理（多 tab 页）

- **🔑 API 密钥管理**
    - 密钥创建与启停
    - 密钥前缀展示与过期管理

- **🔗 Webhook 管理**
    - 订阅配置管理（多 tab 页）
    - 推送日志查看（多 tab 页）

- **🧩 插件管理**
    - 插件注册与查询

- **⚙️ 系统配置管理**
    - 系统配置项增删改查

- **🗑️ 数据保留策略**
    - 数据保留策略配置

- **💬 消息反馈管理**
    - 用户反馈查看与处理

- **💬 聊天测试**
    - 管理员专用测试聊天界面
    - 验证 RAG 问答效果

### 普通用户（USER）

- **🤖 知识库问答**
    - 智能对话界面，流式 SSE 实时输出（带检索/思考状态提示）
    - 支持停止生成（AbortController）
    - Markdown 格式渲染答案
    - 显示引用来源文档
    - 按分类限定问答范围（可选，支持多选）
    - 消息反馈（点赞/点踩）

- **📋 多会话管理**
    - 新建聊天会话
    - 会话分页浏览（支持 10/100/200/300/400 条每页）
    - 会话快速切换
    - 删除历史会话

- **📜 历史记录**
    - 查看历史对话记录
    - 按会话浏览聊天内容

- **👤 个人中心**
    - 查看/编辑个人资料
    - 修改密码

> 💡 管理员同样可访问个人中心页面（`/admin/profile`）。

### 🔧 核心功能

- **RAG 智能问答**：基于向量检索 + Ollama 大模型推理，答案可追溯来源文档
- **文档向量化**：支持多种文档格式，自动解析、分块、向量化存储
- **多租户架构**：租户隔离、配额管控、独立知识库
- **评估体系**：评估数据集 + 评估任务 + 结果明细，量化 RAG 效果
- **Agent 管理**：执行日志 + 长期记忆，支持会话上下文持久化
- **平台化运营**：API 密钥、Webhook 订阅、插件注册、系统配置、数据保留策略
- **实时统计**：多维度数据可视化，直观展示系统运行状态
- **权限控制**：基于角色的路由守卫，精准控制页面访问权限
- **响应式布局**：适配不同屏幕尺寸，提供良好用户体验
